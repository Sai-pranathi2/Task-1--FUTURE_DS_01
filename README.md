# 📊 Online Retail Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes Online Retail Sales Data to identify 
revenue trends, top-selling products, high-value categories, 
and regional performance using Microsoft Excel.

## 🎯 Objectives
- Analyze monthly revenue trends
- Identify top 10 selling products
- Evaluate regional sales performance
- Discover high value product categories

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Charts
- Pivot Tables
- Data Cleaning

## 📂 Dataset
- Source: Kaggle - Online Retail Dataset
- Rows: 541,909 records
- Columns: 8 (InvoiceNo, StockCode, Description, 
  Quantity, InvoiceDate, UnitPrice, CustomerID, Country)

## 📈 Dashboard Contains
- Chart 1: Revenue by Country
- Chart 2: Monthly Revenue Trend
- Chart 3: Top 10 Products by Revenue
- Chart 4: Revenue by Category

## 🔍 Key Insights
- United Kingdom has the highest revenue
- Revenue peaks during November and December
- Top products contribute majority of total revenue
- Europe is the strongest performing region
